# Mihrab: Your Sanctuary for the Quran

A calm, light-themed Islamic web app for reading and listening to the Quran, with a daily Hadith, prayer times and more.

**Live site: https://mihrab.ajanik.dev**

![Home](screenshots/front-light.png)

## Features

- Complete Quran: all 114 surahs with Arabic text, translations and optional transliteration
- Audio recitation with multiple reciters, speed control, sleep timer and a persistent mini-player
- Daily Hadith that stays the same all day and changes at local midnight, with a popup
- Prayer times, Qibla direction and Hijri calendar
- Bookmarks with collections and notes, reading progress and daily goals
- Tasbih counter, adhkar and the 99 Names of Allah
- Light theme by default, with an optional dark mode
- Installable PWA, mobile-first and accessible
